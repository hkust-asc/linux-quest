# linux-quest

**Supercomputer Cadet: Linux X-Ray** is a browser-based Linux CLI learning game for the HKUST ASC student supercomputing team (public identity: ASC Team). This is a team training project, not an official university program or endorsement.

Act 1 (MVP) is being implemented on a feature branch. See the upcoming pull request for the playable game, local run instructions, and GitHub Pages notes.
